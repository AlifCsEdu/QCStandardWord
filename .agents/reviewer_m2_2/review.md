- Independent verification tests confirm that clicking `+ Batch` or `★` toggles batch queue / star state without triggering the card's `handleCopy` micro-interaction or overwriting clipboard state.

### 2.4. Adversarial Stress-Testing

- **Mid-Animation Unmounts**: Fast layout toggling (List → Grid → Table) or query filtering while copied timer is pending executes clean `useEffect` unmount cleanup without memory leaks or dangling timeouts.
- **Multi-Instance Isolation**: Multiple cards copied in sequence operate on independent localized state.
- **HTML/XSS Injection Defense**: Text rendering passes through `escapeHtmlItem` and `searchEngine` highlighting without unsafe DOM evaluation.
- **Zero Forbidden Classes**: Grep search confirmed zero instances of `backdrop-blur-*`.
